# ESP32 LoRa Router MQTT Broker

## English

An ESP32-based project that combines LoRa communication with Access Point (AP) mode WiFi and an embedded MQTT broker. This project transforms the ESP32 into a wireless router that bridges LoRa network messages to MQTT topics, enabling IoT devices to communicate over long distances via LoRa while providing local network access through WiFi AP mode.

### Features
- LoRa to MQTT message bridging
- WiFi Access Point mode
- Embedded MQTT broker on ESP32
- Static IP configuration
- Modular configuration files (WiFi, MQTT, IP, login)
- IoT network gateway functionality

### Hardware
- ESP32 WROOM32
- LoRa module (SX1276/SX1278)

## Português (Brasil)

Um projeto baseado em ESP32 que combina comunicação LoRa com WiFi em modo Access Point (AP) e um broker MQTT embarcado. Este projeto transforma o ESP32 em um roteador sem fio que faz ponte entre mensagens da rede LoRa e tópicos MQTT, permitindo que dispositivos IoT se comuniquem a longas distâncias via LoRa enquanto fornece acesso à rede local através do modo WiFi AP.

### Funcionalidades
- Ponte de mensagens LoRa para MQTT
- Modo WiFi Access Point
- Broker MQTT embarcado no ESP32
- Configuração de IP estático
- Arquivos de configuração modulares (WiFi, MQTT, IP, login)
- Funcionalidade de gateway de rede IoT

### Hardware
- ESP32 WROOM32
- Módulo LoRa (SX1276/SX1278)
